- Ruling: CDP act hit-tests before sending input — DOM.getNodeForLocation at the node's viewport centre (in its own session); the hit node must be the target or its descendant (Runtime.callFunctionOn `this===h||this.contains(h)`), else new error code `ref_occluded` (hint: another element covers it — close the dialog or act on the covering element); no input sent. - Ruling: act `type` — after the click, poll Nodes (settle poll interval) up to 1 s until the target node has state "focused", then type; if it never reports focused, type anyway — cost if wrong: up to 1 s extra on apps that never report focus.

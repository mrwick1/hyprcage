- Fix: the VM install test looked for the old registration command (PR #38).

## Report pipeline

- The audit log records the target of each pointer action (role, name, position), the length of typed text instead of the text, and command arguments through the redactor (PR #31).
- `offstage replay` runs a report trace again and prints `reproduced` or `needs-repro` (PR #31).
- Crash capture: a tool panic returns the error code `internal` and writes a crash file. A fatal crash goes to `crashes/live-<pid>.log` and the next start picks it up. `report_issue` with `area: "crash"` attaches the files (PR #32).
